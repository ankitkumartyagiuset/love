# A Little Universe For You ❤️

A simple romantic surprise website made with HTML, CSS and JavaScript.

## Project files

- `index.html` - website content
- `css/style.css` - colors, layout and animations
- `js/script.js` - buttons, music, stars and download feature
- `assets/music/` - place your own music file here if you want local music
- `assets/images/` - original galaxy, moonlight, roses, and hearts backgrounds

## Run on your computer

1. Extract the ZIP file.
2. Open the `A-Little-Universe` folder.
3. Double-click `index.html`.
4. Click **Open your surprise**. Music should start after this click.
5. Use the music button at the top to turn music on or off.

For offline music, add your own licensed MP3 as `assets/music/romantic.mp3`, then replace the audio source in `index.html` with:

`<source src="assets/music/romantic.mp3" type="audio/mpeg">`

## Free hosting

### GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the public website link.

### Netlify
1. Open https://app.netlify.com/drop
2. Drag the extracted project folder onto the page.
3. Netlify will create a public website link.

## Download button

At the end of the website, the visitor can download a designed, single-page PDF note with the name they entered. It does not collect or send their name anywhere.
